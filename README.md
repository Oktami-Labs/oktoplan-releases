# OktoPlan for Mac

[Download the latest OktoPlan release](https://github.com/Oktami-Labs/oktoplan-releases/releases/latest)

Choose the `.dmg` installer for your Mac:

| Mac | Installer ending |
| --- | --- |
| Apple silicon (M1, M2, M3, M4 and newer) | `macOS_arm64.dmg` |
| Intel | `macOS_x64.dmg` |

Open the disk image, drag **OktoPlan** into **Applications**, then open it from Applications.
The local Qwen and Parakeet transcription models require an Apple silicon Mac running macOS 15 or newer.

OktoPlan checks for signed updates automatically. You can also open **Settings → Account → App updates → Check for updates**.
When an update is ready, choose **Restart to update** after recording or transcription has finished.
Replace older installations once with the current installer to enable these updates.

This public repository contains the official installers, signed update archives, release notes,
and SHA-256 checksums. The application source remains private. Published versions are retained
and are never overwritten.

[Use OktoPlan in your browser](https://vault.oktami.com)
